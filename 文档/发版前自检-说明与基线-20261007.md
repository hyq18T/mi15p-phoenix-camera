## 四、踩过的坑（已修，写进脚本）

1. **`Sh1` 单行退化**：PowerShell 中 `@(...)` 只有一行时管道结果退化成 `string`，
   `$x[-1]` 取到的是**最后一个字符**（`222392852` → `2`、`69` → `9`），
   于是「体积校验」「odm 计数」全部误报。修法：`$x = @(...)` 强制数组化后再取 `$x[$x.Count-1]`。
2. **`cmd package list packages --show-versioncode` 是多行**：
   `com.android.camera` 会连带返回 `com.android.cameraextensions`，
   取末行会拿到 extensions 的 `36`。修法：按 `^package:<包名> ` 精确过滤。
3. **`.ps1` 必须 UTF-8 BOM**：否则 Windows PowerShell 5.1 把中文读成乱码并报
   `Missing closing ')'`（脚本里有中文注释与中文字符串）。
4. **临时文件不放系统 TEMP**：`adb pull` 的临时 APK 改放项目 `99_临时\`，用完即删，符合项目目录规则。
